## 🎯 Sobre o Projeto

Este projeto tem como objetivo explorar a relação entre os hábitos cotidianos dos estudantes e seu desempenho acadêmico, utilizando técnicas de **Análise Exploratória de Dados (EDA)** e visualização de dados.

A proposta surgiu como uma iniciativa de aprendizado prático em Ciência de Dados, buscando compreender como diferentes fatores, como tempo de estudo, saúde mental e utilização de plataformas digitais, podem estar associados ao rendimento escolar.

Por meio de análises estatísticas e representações gráficas, foram investigados padrões, tendências e possíveis correlações presentes nos dados.

## 🛠️ Tecnologias e Ferramentas

As seguintes ferramentas e bibliotecas foram utilizadas no desenvolvimento:

- **Python:** linguagem de programação utilizada para manipulação e análise dos dados.
- **Jupyter Notebook:** ambiente utilizado para desenvolvimento e execução das análises.
- **Pandas:** organização, manipulação e exploração dos dados.
- **Seaborn:** criação de visualizações estatísticas.
- **Matplotlib:** construção e personalização de gráficos.
- **Análise Exploratória de Dados (EDA):** identificação de padrões, tendências e relações entre variáveis.

## 📊 Análises e Técnicas Aplicadas

Durante o projeto, foram utilizadas diferentes técnicas de visualização para investigar a relação entre os hábitos dos estudantes e suas notas.

### 1. Matriz de Correlação (Heatmap)

Utilização de um mapa de calor (*Heatmap*) para identificar correlações positivas e negativas entre as variáveis do conjunto de dados.

Principais observações:

- 🟢 **Correlação positiva:** melhores índices de saúde mental estão associados a notas mais altas.
- 🟢 **Correlação positiva:** maior tempo dedicado aos estudos está associado a um melhor desempenho acadêmico.
- 🔴 **Correlação negativa:** maior tempo de utilização de Netflix e redes sociais está associado a notas menores.

### 2. Regressão Linear

Aplicação de uma linha de regressão linear para representar a tendência da relação entre as horas de estudo e as notas dos estudantes.

O gráfico apresentou uma tendência positiva, reforçando a associação observada entre essas duas variáveis.

### 3. Análise de Distribuição e Agrupamento

Foi realizada uma análise da distribuição das horas dedicadas às redes sociais, agrupando os estudantes de acordo com o tempo de utilização.

O objetivo foi comparar o desempenho médio dos diferentes grupos, permitindo investigar questões como:

- Qual é a média das notas dos estudantes que utilizam redes sociais por aproximadamente 1 hora?
- Como se comportam as notas dos estudantes que passam 4 ou 5 horas nessas plataformas?
- Existe uma tendência de redução do desempenho conforme aumenta o tempo de utilização?

Essa abordagem possibilitou uma comparação mais intuitiva entre os hábitos digitais e o rendimento acadêmico.

O desenvolvimento deste projeto proporcionou experiência prática em diferentes etapas do processo de análise de dados:

- Manipulação e exploração de conjuntos de dados com Python.
- Identificação de correlações entre variáveis.
- Construção e interpretação de Heatmaps.
- Utilização de gráficos de dispersão.
- Aplicação e interpretação de regressão linear.
- Análise de distribuição e agrupamento de dados.
- Utilização de Seaborn e Matplotlib para visualização de informações.
- Transformação de dados em informações visuais para facilitar a interpretação.

## 📌 Conclusão

A análise permitiu identificar associações interessantes entre os hábitos dos estudantes e seu rendimento escolar.

Os resultados apontaram que fatores como tempo dedicado aos estudos e saúde mental apresentam correlações positivas com o desempenho acadêmico. Por outro lado, o maior tempo de utilização de plataformas de entretenimento e redes sociais apresentou correlação negativa com as notas.

O projeto reforça a importância da Ciência de Dados na identificação de padrões e na transformação de dados em informações que podem contribuir para uma melhor compreensão de diferentes fenômenos.

**Importante:** as correlações identificadas não significam necessariamente causalidade. Ou seja, os resultados apontam associações entre as variáveis, mas não comprovam que um determinado hábito seja a causa direta de um melhor ou pior desempenho escolar.
